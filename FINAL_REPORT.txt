```csharp
// Fonctionne exactement comme avant
```

### Mode Injecté (Nouveau)
```csharp
// DI Configuration
services.AddSingleton<IAssetTypeRegistry, DefaultAssetTypeRegistry>();
services.AddSingleton<ITaxCalculationEngine, TaxCalculationEngine>();
services.AddSingleton<IPenaltyCalculator, DefaultPenaltyCalculator>();

// Utilisation
public class TaxService
{
    public TaxService(
        IAssetTypeRegistry assetRegistry,
        ITaxCalculationEngine engine,
        IPenaltyCalculator calculator)
    {
        // Injection de dépendances entièrement testable
    }
}
```

### Extension Personnalisée
```csharp
// Ajouter un nouveau type d'actif sans modifier le code existant
public class CustomAssetTypeDefinition : IAssetTypeDefinition
{
    public string AssetTypeKey => "CUSTOM";
    public AssetType Build() { /* ... */ }
}

// Enregistrer
var registry = DefaultAssetTypes.GetRegistry();
registry.Register(new CustomAssetTypeDefinition());
```

## ?? VIOLATIONS IDENTIFIÉES POUR PHASE 2

### LSP (Liskov Substitution)
- `TaxDeadline` hierarchy viole LSP
- Solution: Composer plutôt qu'héréditer
- Impact: Moyenne priorité

### ISP (Interface Segregation)
- Interfaces actuelles peuvent être plus fines
- Créer `IAssiettePenaltyRule` et `IRecouvrementPenaltyRule`
- Créer `ITaxRuleExpressionEvaluator` spécialisée
- Impact: Basse priorité

### Autre Améliorations
- Créer `ServiceCollectionExtensions` pour DI
- Supporter les plugins custom asset types
- Ajouter validation des définitions
